# Roteiro de teste na pastelaria

Use um **celular** (como cliente) e um **computador ou tablet** do balcão (como equipe). Anote o resultado de cada passo. O que der problema vai para a lista de correções e para o relatório (etapa de Verificação do PDCA).

| 1 | No celular, abrir o app, escolher 2 pastéis e 1 bebida, escolher **Entrega**, preencher telefone e endereço e tocar em **Enviar pedido**. | Aparece a tela do pedido com o número e a etapa **Recebido**. | | |

| 6 | No celular, tocar em **Enviar pelo WhatsApp**. | O WhatsApp abre com o pedido completo para o número da pastelaria. | | |
